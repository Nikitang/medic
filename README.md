# Med Clinic — Frontend медицинской клиники

Адаптивный веб-сайт для медицинской клиники с возможностью записи на прием, просмотра врачей и услуг. Проект выполнен в рамках дипломной работы. Роль: **фронтенд-разработчик**.

---

## О проекте

Сайт позволяет пациентам:
- просматривать информацию о клинике, врачах и услугах
- фильтровать врачей по специализации
- регистрироваться и входить в личный кабинет
- записываться на прием к выбранному врачу
- просматривать и отменять свои записи
- оставлять заявку на обратную связь (консультацию)

Интерфейс адаптирован для десктопов, планшетов и смартфонов.

---

## Технологический стек

**Фронтенд:**
- React 18
- TypeScript
- Redux Toolkit (управление состоянием)
- Axios (HTTP-запросы)
- SCSS (стилизация, адаптивная верстка)
- Webpack (сборка)
- ESLint, Stylelint (качество кода)

**Бэкенд (демонстрационный):**
- Node.js + json-server (эмуляция REST API)
- Файловое хранилище (db.json)

**Архитектура:**
- Feature-Sliced Design (FSD)
